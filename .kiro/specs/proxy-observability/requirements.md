# Requirements Document

## Project Description (Input)
Proxy and direct-provider operators and AI-agent users need correlated, actionable diagnostics for Vibe OIDC, streaming and tool conversations as OpenCode changes. Current diagnostics lack end-to-end traces and metrics. Build on the current structured logging foundation to add safe OpenTelemetry correlation, traces/metrics, opt-in export and operator guidance, preserving streaming, helper protocol stdout and credential privacy. See brief.md; requirements/design/tasks are future phases.
